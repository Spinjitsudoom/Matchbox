# Future Features

Use this file to capture feature ideas before they are ready for implementation.
Keep entries short at first, then expand them when an idea becomes actionable.

## How to Use This File

- Add rough ideas under `Inbox`.
- Move clearer ideas into a category below.
- Use the status labels to show progress:
  - `Idea` - captured, not planned yet
  - `Research` - needs investigation or design
  - `Planned` - ready to break into tasks
  - `In Progress` - actively being built
  - `Done` - implemented and verified
- Add notes about risks, dependencies, or user workflows when useful.
