## 2. Config save location fix

**Problem:** `_data_dir()` in `api.py` only used `~/Documents/Media Manager` when running as a packaged binary (`sys.frozen`). In dev mode it fell back to the project root.

**Fix:** Removed the `sys.frozen` guard so config is always written to `~/Documents/Media Manager/`.

**File changed:** `api.py:32–38`

```python
# Before
def _data_dir() -> Path:
    if getattr(sys, 'frozen', False):
        d = Path.home() / "Documents" / "Media Manager"
    else:
        d = Path(__file__).parent
    d.mkdir(parents=True, exist_ok=True)
    return d

# After
def _data_dir() -> Path:
    d = Path.home() / "Documents" / "Media Manager"
    d.mkdir(parents=True, exist_ok=True)
    return d
```

## 3. Settings failing to save — backend crash fix

**Problem reported:** Settings failing to save.

**Root cause found:** `~/Documents/Media Manager/backend.log` showed:
```
ERROR: Error loading ASGI app. Could not import module "api".
```
The backend crashed at startup before any requests were handled.

**Why:** `uvicorn.run("api:app", ...)` passes the module name as a **string**. PyInstaller only traces static imports and cannot see this reference, so `api.py` and `tmdb_engine.py` were silently omitted from the bundle.

**Fix:** Added both to `hiddenimports` in `backend.spec`:

```python
hiddenimports += [
    'api',
    'tmdb_engine',
    'faster_whisper.assets',
    ...
]
```

**File changed:** `backend.spec:12–13`  
**Commit:** `c04539a Fix backend crash: bundle api and tmdb_engine modules`  
**Pushed to:** `https://github.com/Spinjitsudoom/TMDB-Media-Manager`  
**Rebuilt:** AppImage + Flatpak in `complete builds/`
